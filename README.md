# Portofolio Profesional - Kennedi Sianturi, S.Kom

Website portofolio interaktif dan modern untuk **Kennedi Sianturi, S.Kom**, menampilkan pengalaman profesional, rekam jejak karir di bidang IT, Web Development, Administrasi Keuangan/Audit, Sistem Keamanan (CCTV/Fingerprint), dan Desain Grafis / Media Sosial.

---

## 🌟 Fitur Utama
- **Desain Modern Executive Tech**: Glassmorphism, animasi partikel canvas interaktif, dan dukungan Tema Gelap (Dark Mode) & Terang (Light Mode).
- **Interactive Experience & Project Filter**: Filter pengalaman dan showcase proyek berdasarkan kategori (*IT & Web, Administrasi, Desain & Sosmed, Keamanan*).
- **Matriks Keahlian & Software Suite**: Visualisasi penguasaan tools kantor (Excel, Word, PowerPoint), Photoshop, serta keahlian IT & keamanan.
- **WhatsApp Instant Message Builder**: Pengunjung/recruiter dapat mengirim pesan terformat secara langsung ke WhatsApp.
- **Digital Resume / Print PDF View**: Format CV standar formal siap cetak atau simpan sebagai PDF.

---

## 🛠️ Teknologi yang Digunakan
- **HTML5 & CSS3** (Custom Modern Design System & Glassmorphism)
- **JavaScript (ES6+)** (Canvas Particles, Dynamic Typewriter, Modal Dialogs, Interactive Filters, WA Message Generator)
- **Vite** (Modern Fast Bundler & Dev Server)
- **Font Awesome & Google Fonts** (Outfit, Plus Jakarta Sans, JetBrains Mono)

---

## 🚀 Cara Menjalankan Secara Lokal

```bash
# 1. Clone repository
git clone https://github.com/USERNAME/kennedi-sianturi-portfolio.git

# 2. Masuk ke direktori
cd kennedi-sianturi-portfolio

# 3. Install dependensi
npm install

# 4. Jalankan server lokal
npm run dev
```
